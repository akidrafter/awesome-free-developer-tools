# Awesome Free Developer Tools

> A community-driven list of genuinely free tools and resources for developers.

## Code Editors
- [VS Code](https://code.visualstudio.com/) - Extensible code editor by Microsoft.

## Free Hosting
- [GitHub Pages](https://pages.github.com/) - Host static websites directly from your repo.
- [Vercel](https://vercel.com/) - Fast deployment for front-end frameworks.
